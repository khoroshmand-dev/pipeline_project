
# PostPipeLine

Учебный конвейер обработки постов из JSONPlaceholder. Проект демонстрирует три модели конкурентности в Python, каждая из которых применена там, где подходит лучше всего

## Для запуска необходимо выполнить следующие шаги:

1. Создать и активировать виртуальное окружение (по желанию):

   Создание виртуального окружения:
   ```bash
   python -m venv .venv
   ```

   Активация на Windows (PowerShell):
   ```powershell
   .venv\Scripts\Activate.ps1
   ```

   Активация на Linux/macOS:
   ```bash
   source .venv/bin/activate
   ```

2. Установить из `requirements.txt` все необходимые зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Запустить скрипт `main.py`:

   ```bash
   python main.py
   ```

### Architecture Choices

Для работы с сетью использовали asyncio, так как он позволяет эффективно отправить множество запросов к API. Позволяет выполнять другие задачи, пока ожидает ответ.

Для вычислений использовали multiprocessing, он позволил эффективно распределить нагрузку. Так как мы искусственно утяжеляем процесс обработки.

Для сохранения использовали threading, запись в файл — I/O-bound задача. Во время ожидания операции ввода-вывода другие потоки могут продолжать работу
